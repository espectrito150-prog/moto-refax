# MOTO REFAX · Catálogo digital

Catálogo web adaptable para MOTO REFAX. Incluye 24,522 referencias, búsqueda por nombre, marca y código, filtro por categoría, ficha de producto y cotización por WhatsApp. Los precios no se publican.

## Desarrollo y publicación

- Ejecutar `npm run build` para generar `dist/`.
- En Render, elegir un sitio estático, usar `npm run build` como comando de construcción y `dist` como directorio publicado.

El archivo `catalog.json.gz` conserva el catálogo completo en formato comprimido. La interfaz no ofrece filtros ni muestra información de procedencia.
